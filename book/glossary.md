# Glossary

Terms below use the meanings applied in this curriculum. See the [references](references.md) for formal specifications and domain methods.

| Term | Meaning in these labs |
|---|---|
| Accessibility | Ability to reach an available service, modeled here using fictional travel time. |
| Ascertainment | Process by which cases are detected and recorded. |
| Basemap | Geographic context behind an analytical layer; it is not the analysis itself. |
| Case definition | Criteria used to decide whether an observation belongs in a case count. |
| Choropleth | Areas colored by a metric, usually normalized when populations differ. |
| Common operating picture | Shared view of the situation, evidence, and unresolved questions. |
| Confidence interval | Range from a stated statistical procedure; not all sources of uncertainty are included. |
| Coordinate reference system (CRS) | Rules that relate coordinates to locations on Earth or another defined space. |
| CORS | Browser rules controlling access to resources from another origin. |
| Cumulative incidence | New cases during an interval divided by the population at risk at its start. |
| CZML | Cesium's JSON-based format for time-dynamic geospatial scenes. |
| Denominator | Reference population or person-time used to normalize a numerator. |
| Dijkstra algorithm | Shortest-path method for graphs with non-negative edge weights. |
| Ecological fallacy | Incorrectly attributing group-level relationships to individuals. |
| Ellipsoid | Smooth mathematical approximation to Earth's shape; different from terrain. |
| Emergency Operations Center (EOC) | Coordination setting for information and response activities; this site simulates a small part of that workflow. |
| Epidemic curve | New cases plotted by an explicitly defined time variable such as onset date. |
| Evidence bundle | Computed records, units, stable IDs, and limitations supplied for a briefing. |
| Extrusion | Extending a polygon vertically; here it encodes a metric rather than elevation. |
| Feature | Geometry plus attributes describing one geospatial object. |
| Freshness | Age of an observation relative to a stated clock and threshold. |
| GeoJSON | Standard JSON representation of geospatial features; positions use longitude then latitude. |
| Georeferencing | Relating raster cells or other coordinates to a geographic reference. |
| Great-circle distance | Shortest surface distance on an idealized sphere, used here for proximity. |
| Incidence rate | New events divided by accumulated time at risk; not calculated by the basic outbreak fixture. |
| Ion | Cesium's asset and streaming platform; not required by the default scene. |
| Jupyter Book | Tool used to publish the guide and rendered notebooks as a static book. |
| JupyterLite | Jupyter environment running kernels in the browser rather than a remote Python server. |
| Latitude | Angular position north or south of the equator. |
| Longitude | Angular position east or west of the prime meridian. |
| MAUP | Modifiable areal unit problem: aggregation boundaries and scale change statistical patterns. |
| NDWI | Ambiguous family of water-related indices; Lab 09 explicitly uses green/NIR for open-water illustration. |
| Onset date | Date symptoms or a defined event began, distinct from the reporting date. |
| Person-time | Sum of time that individuals contribute while at risk. |
| Prevalence | Existing cases in a population at a time or over a stated period. |
| Provenance | Origin and transformation history of data, including source and observation time. |
| Pyodide | Python runtime compiled for WebAssembly and used by these browser notebooks. |
| Raster | Grid of cells with values, resolution, and potentially geographic reference. |
| Reporting delay | Time between an event or onset and its report. |
| Resium | React components and context for CesiumJS; used by upstream World View. |
| Responses API | OpenAI interface used by the optional local Astra briefing runner. |
| Scene | Composition of spatial objects, camera, lighting, data, and time. |
| Sensitivity analysis | Changing assumptions or parameters to see whether conclusions change. |
| Structured Outputs | Model output constrained by a JSON schema; still requires factual review. |
| Synthetic data | Invented data for demonstration, with no claim to be observations. |
| UTC | Coordinated Universal Time, used for scenario and provenance timestamps. |
| Vector data | Points, lines, and polygons, contrasted with raster grids. |
| WebGL | Browser graphics interface used for the Cesium 3D rendering. |
| WGS 84 | Geographic reference system underlying GeoJSON positions in these labs. |
| Wilson interval | A binomial-proportion confidence interval used for a limited teaching model. |
